🩺 Breast Cancer Prediction Using CNN

A deep learning project for breast cancer image classification using a Convolutional Neural Network (CNN). The model learns visual patterns from breast tissue images and classifies them into the corresponding diagnostic categories.

Disclaimer: This project is intended for educational and research purposes only. It is not a medical diagnostic system and should not be used for clinical decision-making.

📌 Project Overview

Breast cancer is one of the most common cancers worldwide, and early detection can play an important role in improving treatment outcomes.

In this project, a Convolutional Neural Network (CNN) is developed to automatically classify breast cancer images based on visual patterns present in the dataset.

The complete dataset contains approximately 277,000 images. Due to computational and training constraints, a subset of the dataset was used for model development:

50,000 images → Training
10,000 images → Testing
Remaining images → Not used in the current training experiment

The objective is to build a deep learning model capable of learning meaningful image features and accurately classifying breast tissue images.
